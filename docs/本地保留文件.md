整理时没有删除文件。原 `D:/hdmi/redesign`、厂家示例、旧 `use` 和旧写卡工具均保留。`useing` 工作目录里复制后未采用的参考文件也保留在磁盘上，通过 `.gitignore` 排除；它们不进入 Git clone 或发布 ZIP。

| 本地路径 | 排除原因 |

| `.runtime/` | 离线依赖解压结果，可从 `vendor/` 重新生成 |

此表用于用户自行判断本地文件用途，不表示已执行清理。工程不包含删除、自动清理或 `git clean` 命令。编译和刷新工具环境都使用新目录保存结果。
