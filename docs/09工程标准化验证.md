## 工程约定

- `td_project/*.al` 是工程源文件列表的唯一入口，源码和约束使用相对路径。
- HDL 放在 `user_source/hdl_source/`，板卡约束放在 `user_source/constraints_source/`；专项回归放在 `sim/` 并纳入 `test.cmd`。
- `setup.cmd`、`media.cmd`、`test.cmd`、`build.cmd`、`package.cmd` 分别承担初始化、媒体制作、回归、编译与分发。
- 当前固件、SHA256 清单及精选最终报告进入 `firmware/`；仿真预览进入 `docs/evidence/`，不引用被忽略的临时输出。
- `.runtime/`、`build/`、`output/`、`dist/`、用户媒体和本机设置保持在 Git 外。旧构建及本机资料继续保留。
- 用户操作文档描述当前版本，开发阶段的资源变化记录归入 `docs/history/`。
