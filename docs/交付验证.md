## 完整像素回归

含空格路径的克隆目录执行 `test.cmd -Full` 全部通过，日志为 `evidence/portable_clone_full.log`。除快速回归外，真实 JPEG 核完整输出 **307200 像素**，与独立软件 JPEG 解码比较的平均通道误差 **MAE=0.216349/255**；仿真报告解码耗时 23,956,188 ns。该值为仿真中的解码路径耗时，不等同于包含实际卡延迟的整机帧率。

最终交付只补充验证文档与证据，功能文件沿用上述通过验证的版本。最终 ZIP 重新导出并检查文件清单和 SHA256，报告中的克隆/解压测试不依赖原工作目录的缓存。

## 保留与使用边界

未删除原工程、旧工具、旧素材或历史构建。JPEG 核的原 Git 元数据保存在 `.local/core-jpeg-upstream-git/`，不进入发布包；本地参考文件用途见 `本地保留文件.md`。

本次验证不包含物理卡写入，也未对实际无丢帧帧率或音画偏差进行仪器测量。详细上板检查表见 `测试流程.md`。
