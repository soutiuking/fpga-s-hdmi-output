# SW4 音频波形

SW4（L13，用户引脚序号 30）拨下至 ON 后，在 HDMI 画面左侧显示实时音频振幅包络，拨回后隐藏。与 SW3、SW0～SW2 独立，可以在视频播放时同时显示，不改变 S0/S1 功能。

由于 DSP 已用满，采用无需乘法器的时域波形，而非 FFT 频谱。数据直接取自视频时钟域中已有的 HDMI I2S 接收器，使用音量调整后的左声道 PCM24 高 8 位，在相邻显示帧之间持续计算有效样本的最小值和最大值，每帧提交一格；约 60 Hz HDMI 刷新下每格约 16.7 ms，32 格共约 0.53 秒。最旧数据位于左侧，最新数据位于右侧，每格宽 4 像素。左右声道当前来自相同单声道 PCM。

面板范围为 `x=8..151, y=88..375`，深色半透明背景、天蓝边框、青绿色波形和薄荷色包络边缘；中心线为 y=232，波形范围 y=105..360。位置避开上方滚动文字和下方设置条。音量调低时波形幅度减小，静音后最新格在下一显示帧变为水平线，约 0.53 秒后整条历史成为水平线；仅使用高 8 位，因此极小振幅可能显示为平线。没有有效音频样本时保持历史；持续零样本则更新为平线。

历史使用寄存器存储，每帧首个有效像素将当前振幅包络写入并滚动一次历史，扫描过程中历史保持稳定，避免撕裂；无需双份历史缓存。开关经消抖、两级同步后在帧边界生效。新增一级 RGB/DE/VS 同步流水，不改动音频背压、播放时间轴或帧缓存。

RTL 仿真覆盖有符号极值、按帧分箱、首末样本、32 格历史滚动、无样本保持、帧内历史稳定、静音、开关、逐像素渲染和 640×480 AXI SOF/EOL 对齐；顶层测试覆盖 SW4 连线及设置模式独立性，HDMI CDC 测试覆盖已有帧完成跨时钟通路。实板声音与画面联动尚待下载验收。
