# 自定义字幕与上位机预览

双击根目录 `media.cmd` 打开图形界面。命令行 `pack`、`inspect`、`disks`、`write` 继续可用。

## 制卡和使用

1. 在“媒体与写卡”添加图片或视频，用上移、下移调整播放顺序。选择图片自动预览，选择视频自动静音预览；可以重播、停止或输入秒数定位。制卡是否保留音轨由“保留声音”单独控制。
2. 在“字幕设置”输入最多 10 条字幕，每条最多 32 个字符，中英文均占一个字格。使用与原默认文字相同的黑体 SimHei，固定 16×16 点阵，在板上放大到 32×32；字体不可选。每条可以选择 RGB 颜色，或开启炫彩文字。
3. 点击某行的预览查看点阵效果。窗口展示前 19 字，FPGA 会滚动展示整条字幕。炫彩预览展示其中一帧。字幕配置可以单独保存、载入 JSON。
4. 点击“仅生成镜像”，字幕点阵会与媒体一起写入镜像。空行忽略，顺序按非空行压缩；全部为空则不写字幕扩展。修改字幕后需要重新制卡。
5. 在“TF 卡设备”按盘符、卷标、容量和型号选择，勾选覆盖确认后点击“生成并写入 TF 卡”或“写入已有镜像”。写卡需管理员身份；最终弹窗显示设备详情，要求输入“磁盘 N”。设备不会自动选中，移除或身份变化会清除确认；后端写前重新核对身份，完成后全量回读 SHA256 校验。
6. 下载支持自定义字幕的 12 版固件。SW3 拨下时显示字幕；有自定义数据时，S0 切下一条、S1 切上一条，到末尾循环。SW3 拨回后，S0/S1 恢复下一媒体、暂停/继续。切换模式时需要先松开按键。

SW0 音量、SW1 亮度、SW2 对比度的按键设置优先级更高。三个设置开关都关闭时，SW3 才接管 S0/S1。SW5～SW7 播放信息不占按键。

无字幕、旧卡、字幕 CRC 校验失败或字幕加载超时，都回退到 `fpga真有意思，真好玩`，保持原来的金色英文和炫彩汉字；此时 SW3 不接管 S0/S1。开机默认选择第一条，自定义字幕选择在本次通电期间保持，切换媒体不重载字幕。

## 实现和兼容性

上位机负责字体栅格化，FPGA 只保存并读取单色点阵，再按所选颜色叠加。因此不会在 FPGA 内增加完整中文字库，也不增加 DSP。字体文件使用 Windows 自带 `C:/Windows/Fonts/simhei.ttf`；缺失时会提示安装 SimHei，不能随意替换成其他字体。

自定义字幕固定占 22 个扇区（11264 字节）：1 个头扇区、21 个带 CRC 的点阵扇区。启动阶段利用目录读取通道加载一次，播放时不再占用 SD 带宽。多位配置使用请求/确认邮箱跨时钟域，字幕选择和颜色在帧边界生效。

旧卡可直接由新固件播放；旧固件可以播放新镜像中的媒体，但忽略自定义字幕。格式仍为 TFMEDIA3 v3，扩展字段见 [格式说明](TFMEDIA3_FORMAT.md)。媒体与 HDMI 规格仍为 640×480、25 fps。

## 验证

`test.cmd` 包含点阵格式往返、长度和颜色限制、全部扇区 CRC、旧卡兼容、FPGA 字幕加载及错误回退、10 条双向循环切换、按键隔离、固定色和炫彩叠加、视频同步及既有播放器回归。

上位机可运行以下自动冒烟测试；会启动窗口后自动关闭，不操作物理磁盘：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/setup_gui.ps1
# 使用 .runtime/gui-current.json 指定的 python 执行：
python tools/media_gui_tk.py --smoke-test
```

它验证 10 行编辑器、固定字体预览、中文路径图片与视频、视频定位，以及界面异步生成带字幕镜像。截图写到 `build/tk-media.png`、`build/tk-subtitles.png`、`build/tk-video.png` 和 `build/tk-card-demo.png`，报告写到 `build/tk-gui-validation.json`。设备演示截图使用明确标注的模拟数据；自动验证禁止调用物理写入。实板显示、卡启动和物理按键效果仍需上板验收。

命令行配置示例：

```json
{
  "subtitles": [
    {"text": "欢迎观看 FPGA 多媒体演示", "color": "#22D3EE", "rainbow": false},
    {"text": "固定字体彩色滚动字幕", "color": "#FDE68A", "rainbow": true}
  ]
}
```

```powershell
.\media.cmd pack .\demo\color_bars.png --subtitles .\demo\subtitles.json -o .\output\subtitles.img
```

## 原版布局与独立工具

根据用户提供的原版 Tk 工具重做媒体列表、右侧预览和底部制卡区，新增独立字幕页与任务记录。原版视频区域仅提供文件信息，新版使用随包 FFmpeg 实际播放，并支持按秒定位。图片使用 Pillow 读取、处理 EXIF 旋转并保留 Tk 图像引用，避免预览空白；所有界面刷新均在主线程完成。设备扫描和转码在后台执行，避免阻塞界面或弹出命令行窗口。

工程内 `media.cmd` 默认启动新版。`tools/setup_gui.ps1` 检查 GUI 离线依赖的大小及 SHA256，独立建立 Python 3.11/Tk 运行时，不更改 FPGA 测试所用的 Python 3.12。`tools/package_media_tool.py` 生成带 `FPGA_TF_Media_Tool.exe` 的独立文件夹，无需安装 Python 或 FFmpeg；复制时须保留整个文件夹。支持 Windows 10/11 x64，固定字幕字体要求系统有 SimHei。

新版已通过独立 EXE 启动、中文及空格媒体路径、图片预览、视频播放与定位、字幕预览、媒体/音频/字幕镜像生成和完整镜像检查。设备保护测试覆盖拔卡、磁盘编号复用、容量/序列号/路径变化、裸卡及系统盘保护。当前电脑未接入 TF 卡，仅查询到了内置 NVMe；物理写卡和实板播放仍待接卡验收。

## 设备扫描重复启动修复

删除原每 10 秒启动 Python/PowerShell 的定时设备扫描，改用 Windows `WM_DEVICECHANGE` 插拔通知。仅启动、设备变化、手动刷新时查询设备；连续通知合并为一次，任务执行中延后查询。收到设备变化立即清除目标及覆盖确认，写卡前的后端身份复核保持。若插拔通知注册失败，任务记录提示手动刷新，不恢复定时查询。PowerShell 查询在隐藏窗口的后台子进程内运行。

`sim/check_gui_device_notifications.py` 使用真实 Windows 消息和模拟磁盘清单，检查 22 秒空闲期只有一次启动查询、插拔通知合并、清除确认、任务期间延后及手动刷新；不打开物理磁盘。
