12 版新增自定义字幕后，最终 LUT=16812/19600、BRAM9K=53/64，DSP 和 BRAM32K 已满；MSlice=4883/4900，打包容量比 LUT 总数更先成为瓶颈。下文历史余量不能直接作为当前可扩展资源，继续增加 FPGA 功能需要先优化。上位机功能扩展不消耗 FPGA 资源。详见 [12 版资源与报告](../firmware/README.md)。

本页为 10 版历史评估。SW5～SW7 现已实现播放信息；原生 720p 的明确瓶颈及新版本说明见 [720p 评估与播放信息](720p评估与播放信息.md)。

## 优先推荐

以下是建议，当前固件没有新增这些开关功能；SW5～SW7 继续预留。

| 建议开关 | 功能 | 实现方向与预计影响 |
|---|---|---|
| SW5（P14） | 播放进度、媒体序号和时间显示 | 复用已有样本时间轴、帧计数与小字体；预计资源开销较低，需处理暂停及媒体切换 |
| SW6（P16） | 图片渐变开关或速度选择 | 复用现有双图混色器，调整帧间权重推进；预计新增逻辑较少，继续仅对图片启用 |
| SW7（P15） | 灰度或反色显示 | 用移位加法实现灰度，或按位反色；无需新增 DSP，需与亮度、对比度及 OSD 明确处理顺序 |
| 可复用 SW4 | VU 电平、峰值保持与削波提示 | 基于现有 PCM 振幅检测增加显示模式；比完整 FFT 频谱更适合当前资源余量 |

优先顺序建议：渐变开关/速度 → 进度显示 → 灰度/反色 → 音频峰值显示。它们主要增加控制和 OSD，便于复用现有通路。完整 FFT、复杂卷积滤镜或双视频混合需要先优化现有 DSP、存储及带宽，暂不作为直接追加功能推荐。以上没有经过新增功能的实际综合，不承诺具体资源增量或全部同时可容纳。
