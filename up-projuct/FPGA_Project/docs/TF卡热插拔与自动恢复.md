# TF 卡热插拔与自动恢复

此扩展在 12 版自定义字幕固件上增加读卡自动恢复，媒体规格保持 640×480、25 fps。原卡与上位机镜像格式不变。最终 bit、资源及时序结果见固件说明；实板插拔仍需验收。

固件为 [13_player_hotplug.bit](../firmware/13_player_hotplug.bit)，构建 `20261019-215059-170`、布局 seed 11。TD 最终建立裕量 0.227 ns、保持裕量 0.022 ns，无负裕量；LUT 16950/19600、BRAM9K 53/64、MSlice 4880/4900，DSP 和 BRAM32K 用量不变。报告及 SHA256 见 [固件说明](../firmware/README.md)。

复现命令：`build.cmd -Target TFMEDIA3_Player -PlaceSeed 11`，默认布局种子也已更新为 11。工程保留 40 MHz 读卡/JPEG、25 MHz 像素和 125 MHz 存储器时钟及原时序约束。

## 使用行为

- 未插卡上电：保持 HDMI 输出，媒体区域为黑色。初始化等待约 5 秒后，自动复位存储与播放链路，等待约 1 秒再尝试。之后插入有效卡，无需按 RESET。
- 播放中拔卡：在下一次实际读卡时发现超时。单次扇区读取最多等待约 2 秒；超时后清空播放状态并静音，约 1 秒后重新尝试初始化。目录、元数据或 JPEG DMA 自身发现格式/读取错误也会触发恢复。
- 重新插卡：重新读取、校验超级块及媒体信息，从第一个媒体、第一条自定义字幕开始。换成无字幕的旧卡时回到默认文字，不沿用上一张卡的字幕。
- 无效卡：超级块或媒体信息校验失败后继续重试，不显示未通过验证的媒体。镜像仍应由写卡工具完整验证后写入。
- 音量、亮度、对比度及拨码设置不会因自动恢复而复位。手动 RESET 仍执行原整板复位。

当前 TF 接口没有使用卡座检测触点，采用 SPI 响应和读卡超时判断可用性。**暂停且没有实际读请求时，不会立即察觉拔卡；恢复播放或发起下一次读取后才进入超时恢复。**正常图片轮播也可能先完成当前显示周期再发现拔卡。不用 MISO 静态高低电平判断是否插卡，也不额外增加周期读卡探测。

“约 5 秒 / 2 秒 / 1 秒”分别指初始化超时、单扇区看门狗和重试等待；实际插卡到显示还包括 SPI 初始化、目录/字幕加载及首帧解码时间。

## 复位范围

`reset_control.v` 中的 `storage_recovery` 由 40 MHz 读卡时钟驱动。一个计数器分别用于扇区看门狗和重试等待。监督器自身仅接受板级复位，因此不会被自己产生的重试复位困住。

恢复复位覆盖 SD 初始化与命令状态机、扇区仲裁器、目录、字幕加载状态、元数据、JPEG SRAM DMA、音频环形缓冲控制、SRAM 控制器、JPEG 解码和顶层待呈现状态。清零的是缓存有效状态及指针，不额外逐字擦除所有 RAM。

HDMI shell 中对读卡、存储器及像素域分别异步置位、同步释放媒体复位，成对清空显示页握手与完成事件 CDC，同时重置帧缓冲和 SDRAM 控制器。SDRAM 在恢复后重新初始化；无效显示页被遮黑。字幕选择邮箱保留跨域握手，通过清零字幕数量发送无效配置，避免只复位邮箱一端造成旧配置或事件错配。

HDMI 像素时序、视频/音频 PLL、EDID、发送器和 PHY 不接媒体复位；音频包和 I2S 时钟持续运行，媒体无效或暂停时发送零值音频。不会因为自动恢复而主动断开 HDMI 或重新读取 EDID。

## 验证与上板步骤

`test.cmd` 已接入热插拔专项仿真：

- 实际存储前端和恢复监督器，无卡连续重试两次后插入一张有效卡，加载两条自定义字幕和首项媒体。
- 在扇区读取中移除卡，模型保留“初始化完成”但停止响应，验证看门狗能够主动恢复，而非等待初始化标志掉线。
- 插入损坏超级块的另一张卡，验证拒绝和继续重试；再恢复有效数据，验证无字幕卡不会复用旧字幕。
- 实际顶层故障注入，验证读卡、解码和待呈现缓存清零，静音、设置保留及 HDMI 板级复位隔离。
- 实际 HDMI shell 跨域检查，验证媒体复位清空完成事件、不产生陈旧事件，恢复后能接收新事件，视频全局复位始终不触发。

专项入口为 `sim/check_storage_hotplug.py`，沿用包内 Icarus；SD 仅替换为可插拔协议模型，目录、元数据、字幕、仲裁、DMA 和 SRAM 控制采用生产 RTL。仿真使用缩短计数参数，固件保持上述实际等待时间。

上板验收建议依次进行：无卡上电后等待至少两个重试周期，再插入有效卡；正常播放中拔卡并重新插回；换成不同媒体/字幕卡；换成无字幕卡；暂停后拔卡再恢复播放。检查首项媒体、字幕、静音及音量等设置，并确认显示器持续识别 HDMI 信号。软件仿真和 TD 时序通过不替代卡座接触、电源稳定性、实际 SD 卡兼容性及 HDMI 实测。

最终快速回归与热插拔专项均通过，完整记录见 [验证报告](evidence/hotplug/validation.md)。
